IntroSkip

Skip intros, recaps, previews and credits with community timestamps and Kodi's native chapter data. Install the repository once; Kodi handles future updates.

repository.introskip-1.0.6.zip Select this ZIP from Kodi's Install from zip file screen.

Install in Kodi

  1. Open Settings → File manager → Add source.
  2. Enter https://zoeywowy.github.io/repository.introskip/ and name it IntroSkip Repository.
  3. Open Add-ons → Install from zip file and select the IntroSkip Repository source.
  4. Choose the ZIP listed above. Kodi will install the repository add-on.
  5. Open Install from repository → IntroSkip Repository → Services → IntroSkip and install IntroSkip.
IntroSkip is an independent community add-on for Kodi 22. The repository installer enables normal Kodi add-on updates.
