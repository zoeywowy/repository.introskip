IntroSkip for Kodi 22

Install the IntroSkip repository add-on once. Kodi can then install and update IntroSkip through its normal add-on manager.

repository.introskip-1.0.5.zip

Install it in Kodi 22

  1. Open Settings → File manager → Add source.
  2. Enter https://zoeywowy.github.io/repository.introskip/ and name it IntroSkip Repository.
  3. Open Add-ons → Install from zip file.
  4. Select the IntroSkip Repository source. Kodi should list repository.introskip-1.0.5.zip.
  5. Select the ZIP. Kodi installs the repository add-on.
  6. Open Install from repository → IntroSkip Repository → Services → IntroSkip and install it.

Why this works: the ZIP link is relative to this website, matching the A4K repository layout. Kodi can browse the source and see the ZIP as a file. Do not use a separate raw.githubusercontent.com link in the source page.
