IntroSkip for Kodi 22

Install the IntroSkip repository add-on once. Kodi can then install and update IntroSkip through its normal add-on manager.

Download repository.introskip-1.0.5.zip (direct ZIP)

Install it in Kodi

  1. Download the ZIP above in a normal web browser. Do not extract it.
  2. Make the ZIP available to Kodi: use Downloads on Windows, or USB/shared storage on Android TV and Fire TV.
  3. In Kodi, open Add-ons → Install from zip file.
  4. Browse to the downloaded ZIP and select it.
  5. Open Install from repository → IntroSkip Repository → Services → IntroSkip.

Important: Do not add this webpage as a Kodi File Manager source. If Kodi's ZIP browser shows only .. and 0 items, cancel. Download the ZIP in a normal browser, then select the downloaded file from local storage.
