IntroSkip for Kodi 22

Install the IntroSkip repository add-on once. Kodi can then install and update IntroSkip through its normal add-on manager.

Download IntroSkip Repository 1.0.4

Add this source in Kodi

Open Settings → File manager → Add source and enter:

https://zoeywowy.github.io/repository.introskip/

Then choose Add-ons → Install from zip file and select the repository ZIP.
